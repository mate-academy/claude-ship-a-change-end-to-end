**Коміти (підсумок).** Чотири: store-хелпер, роут із валідацією та 404, виправлення після рев'ю, NOTES.md. Тести запускав на кожному коміті: червоні до підключення роуту, зелені після.

**Рев'ю.** Підтвердило, що 404 для неіснуючого та нечислового id працює без падіння, а запит без тіла дає 400, а не 500. Знайшло реальну проблему: загальне повідомлення 400 не називало поле. Виправив окремим комітом (`name is required` / `email is required`). Свідомо не чіпав: унікальність email і м'якшу валідацію в POST (існуюча поведінка, поза обсягом), 404 для нечислового id (так само працює GET).
